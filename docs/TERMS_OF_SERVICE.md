## 2. Description & Scope of Miee

Miee is a music player application built using Flutter. The application provides:
- Offline playback of audio files stored on the user's local device storage.
- Audio metadata extraction, organization (albums, artists, tracks), and local album art caching.
- Optional account creation and cloud database synchronization (playlists, liked tracks, listening history, custom profiles) via Supabase.
- Client-side online audio stream search and playback from public web streams.
- Retrieval and display of synchronized and plain lyrics via public APIs (LRCLIB).
- Group listening sessions via real-time shared listening rooms.

Miee is provided as a utility media player. Miee is **not** an audio publisher, music distributor, record label, or streaming content host.
