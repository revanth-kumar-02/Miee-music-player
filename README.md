# Miee

A premium, minimalist music player application built with Flutter.

## Features

- **Local & Online Playback:** Seamless playback of local audio and online streaming.
- **Listen Together Rooms:** Real-time synchronized listening rooms for hosting and listening with friends.
- **Audio Diagnostics & Reliability:** Background playback wake-lock retention, lock screen media controls, and network drift correction.
- **Minimalist Aesthetic:** Tailored warm palette, responsive layouts across Mobile (Android/iOS) and Web/Desktop.

## Getting Started

1. Ensure Flutter 3.x is installed:
   ```bash
   flutter --version
   ```
2. Install dependencies:
   ```bash
   flutter pub get
   ```
3. Run the application:
   ```bash
   flutter run
   ```
